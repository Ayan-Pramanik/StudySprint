# StudySprint

**Connect your notes. Remember what matters.**

A persistent study application for your own material: linked Markdown notes, source-based flashcard drafts, approval, FSRS reviews, version history, and backup/import. No sample workspace or canned generation is included.

Requires Node 22.13+. See [STUDYSPRINT.md](STUDYSPRINT.md) for setup, configuration, test commands and current limitations.
